# karatap

音遊式的卡拉OK字幕打軸工具。從「影片＋歌詞網頁」開始：貼上帶假名的歌詞，跟著歌用鍵盤先打每一行、再打每個音節，自動排好奇偶兩排的版面，匯出一份在 Aegisub 裡按 Apply Karaoke Template 就能完成的 ASS。

特效仍然在 Aegisub 裡用 Karaoke Templater 做；karatap 負責套樣板之前的所有工作。已經有行時間的 ASS（例如用 Arctime 打好的）也可以直接開來打音節。

## 安裝

### 用打包好的版本（Windows）
1. 從 [Releases](https://github.com/spt22kousis/asskaramaker/releases) 下載 `karatap-<版本>-windows-x64.zip`，解壓縮。
2. 安裝 [ffmpeg](https://ffmpeg.org/download.html) 並加進 PATH（用來讀影片的音訊、產生慢速版本）。
3. 執行 `karatap.exe`。

想確認環境沒問題，可以執行 `karatap.exe --selftest report.txt`，結果會寫進 `report.txt`，最後一行是 `OK` 就沒問題。

### 從原始碼執行
需要 Python 3.13（其他版本沒測過）和 ffmpeg。

```bash
python -m venv .venv
.venv/Scripts/python -m pip install PySide6 sounddevice numpy
.venv/Scripts/python -m karatap
```

也可以直接帶檔案：`.venv/Scripts/python -m karatap 歌詞.ass 影片.mp4`。

## 整體流程

1. **新專案**（Ctrl+N）：選影片、選一份做好的舊 ASS 當樣板、貼歌詞、檢查讀音，建立新的 ASS。
2. **① 行軸**：跟著歌，每一行按一下，打出每行開始和唱完的時間。
3. **② 音節**：逐行跟著歌敲每個音節。
4. **③ 版面與輸出**：確認奇偶版面，按 Ctrl+E 匯出（預設 `檔名.timed.ass`，原檔不會被改）。
5. **④ 預覽**（可選）：跟著音樂看匯出後每行的位置和填色。
6. **套樣板**：在 Aegisub 裡打開匯出的檔案，Apply Karaoke Template。

第一次使用建議先做**延遲校正**（Ctrl+L）：跟著節拍器用打軸鍵或空白鍵敲，前 4 下不計，敲滿 8 下以上就能按「套用」。之後每一下敲擊都會扣掉這個延遲。

每一頁最上面有一行常用按鍵提示，右邊的「操作說明」可以展開完整說明。

## 新專案

### 1. 選檔案
- **影片或音檔**：要打軸的歌。
- **樣板 ASS**：拿一首做好的歌的 ASS。新檔案只沿用它的 `[Script Info]`、樣式和 template／code 行；舊歌的歌詞行、fx 行和其他對白都不會帶過來。樣板檔本身不會被改。留空就用**內建預設樣板**（樣式 K1／K2／K0 等和社團的 template／code 行，版面預設奇數行 K1、偶數行 K2、單行 K0）。
- **歌詞樣式**：奇數行、偶數行和單行（單獨出現的行，單排版面也用它）要用樣板的哪個樣式。有 K1／K2／K0（或 Odd／Even／Default）就預設用它們，沒有就預設用第一個有 template 行的樣式。`-furigana` 結尾的是振假名用的樣式，不會列出來。Aegisub 只會把 template 套在**樣式名稱相同**的行上，選了沒有 template 行的樣式時下面會提醒。之後也可以在「③ 版面與輸出」改。
- **新的 ASS 存到**：預設和影片同資料夾、同檔名。檔案已經存在時會要你換名字，不會覆蓋。

新檔案會記下影片路徑，用 Aegisub 打開時會自動載入影片。

### 2. 貼歌詞
- **最簡單**：在 Utaten 或萌娘百科的歌詞頁，用滑鼠選取整段歌詞按 Ctrl+C，再按「從剪貼簿貼上」。
- 也可以貼網頁原始碼（F12 複製的 HTML）、輸入網址按「抓取」、貼之前 notebook 產生的 `{\k1}` 歌詞行，或直接打字。
- 框框裡 `[漢字|かな]` 代表振假名，一行就是一句，可以直接修改。
- 歌詞沒有假名時，按「複製 LLM 提示詞」，貼到 ChatGPT 等 LLM，再把回答整段貼回框框。

### 3. 檢查讀音
每個漢字會分到自己的讀音，一個字一個音節，例如 `大熱唱|だいねっしょう` → 大（だい）熱（ねっ）唱（しょう）、`物語|ものがたり` → 物（もの）語（がたり）。

| 顯示 | 意思 |
|---|---|
| 綠底線 | 自動分好 |
| 黃底 | 有不只一種分法，請點一下選擇 |
| 灰底 | 分不開（熟字訓，例如 `今日|きょう`），整組當一個音節 |

點任何一個詞都可以換分法（包括「整組不拆」）；雙擊一行可以直接修改文字，換行會拆成好幾行。下面的按鈕可以新增、刪除、合併行。只有標點的行建立時會略過。

建立之後發現歌詞有錯，也可以在行清單按右鍵修改（見[修改行](#修改行)）。

### 拆音節的規則
- 每個假名一個音節；`ん`、`っ`、`ー` 也各自一個；小字（`ゃ ゅ ょ ぁ…`）併進前一個字。
- 漢字一個字一個音節，帶它自己的整個讀音；分不開的整組一個音節。
- 英文一個單字一個音節；數字一個數字一個音節。
- 空白自成一個音節。
- 標點黏在相鄰的音節上；相鄰的是有振假名的音節時改黏另一邊，兩邊都不行就自成一個音節（只有標點的音節不用敲）。

## ① 行軸

播放時，每一行按一下：按下＝這行開始唱，放開＝唱完。可以兩鍵交替，按下一鍵時上一行自動結束。起點模式（M）下只看按下的時間，這行到按下一行或結束鍵 L 時才結束。

畫面上方大字是下一個要按的行，上面黃色的是正在按住的行。左邊清單：○ 還沒打、● 打好了、◆ 已經打好音節（以音節的時間為準）。雙擊某一行可以從那行開始打。

### 全曲時間軸

頁面下方是整首歌的時間軸：波形上每一行一個區塊（開唱～唱完），套用奇偶版面時，最上面兩條細排是每行在畫面上出現～消失的時間（上排奇數、下排偶數，紅框＝出現時已經開唱）。

- 滾輪：左右捲動；Ctrl＋滾輪：以滑鼠位置為中心縮放；拖曳空白處也可以捲動。
- 點一下：跳到那個時間；雙擊區塊：從那一行開始打。
- 暫停時拖曳區塊的左右邊（有小把手的地方）可以調整行軸，每 10ms 一格。
- 已經打好音節的行（綠色）鎖住，要調整請到「② 音節」的波形。
- 播放時會自動翻頁跟著播放線。

## ② 音節

畫面中間的大字是「下一個要敲的音節」，有振假名的會一起顯示；同一個漢字的下一拍（`#|<…`）會標出來。旁邊的小字是接下來的音節。

左邊是行清單：○ 未敲、◐ 敲到一半、● 已敲、⚠ 敲出界、◆ 沿用檔案裡原有的 `\k`。雙擊可以跳到那一行。

### 打軸模式（M 切換）

| 模式 | 怎麼敲 | 音節長度 |
|---|---|---|
| 長按（預設） | 按下＝音節開始，放開＝音節結束 | 按住的時間 |
| 起點 | 只看按下 | 到下一次按下為止 |

- 長按模式可以用好幾個鍵交替敲（像音遊的雙押）：前一鍵還沒放開就按下一鍵，前一個音節就在這一刻結束。
- 按鍵的自動重複會被忽略，長按不會變成連打。
- 長按模式放開後到下一次按下之間的空白：中間有間隔音節就填進去，沒有的話預設併進前一個音節（設定裡可以改成自動插入空的 `{\k}`）。
- 起點模式下，一行最後一個音節的結束預設是放開按鍵，也可以在設定改成按結束鍵（預設 L）。

### 逐行／連續（C 切換）

- **逐行**（預設）：敲完一行會自動跳到下一行的 pre-roll（行開始前 1 秒）。一行結束 1.5 秒還沒敲完（而且沒有按著鍵），就自動重播這一行。
- **連續**：整首不停。一行完全沒敲、而且已經過了行尾 0.3 秒，就跳過那一行。

### 間隔音節

文字是空的、或只有空白和標點（`！`、`「`、`"`、`……` 等）的音節是間隔音節：不用敲，時間由工具填。`&`（唱成 "and"）和 `♡` 這類符號照樣要敲。

### 調整音節切分

暫停時，目前那一行的字與字之間會出現標記：

- **紫線**：現有的分界，點一下合併。
- **灰線**：不能合併的分界，例如振假名音節和一般文字之間，因為 `|<` 後面接的文字會被當成讀音。
- **點**：可以切開的地方，點一下切開。漢字是切讀音（點振假名那一列，例如 `新|<しん` → し／ん），假名是切字。

切分的調整存在進度檔，匯出時才寫進新的 ASS。改到已經打好的行會先問你，因為那行的打軸結果會被清掉。選單「打軸 → 還原目前這行的音節切分」可以改回原本的拆法。

### 波形微調

下方是目前這一行的波形（V 切換成頻譜），藍色區塊是每個音節、實線是開始、虛線是結束、白色點線是行頭行尾。套用版面時，白色點線是「① 行軸」打的範圍（這行的音節打完後就由音節決定，不再顯示）；畫面上什麼時候出現／消失在「③ 版面與輸出」調整。

- 暫停時拖曳邊界可以微調（每 10ms 一格，不會越過相鄰的邊界）；兩個音節相接的地方是同一個把手。
- 一行打到一半暫停時，已經打的音節也可以拖；按空白繼續會從停下的地方接著打。這種拖曳算在這次打軸裡，不能用 Ctrl+Z 單獨復原（Backspace 仍是取消上一下敲擊）。
- Shift＋拖曳優先抓行頭／行尾（套用版面時＝改這行的行軸）。
- 點波形其他地方＝把播放位置移過去。
- Ctrl＋滾輪：以滑鼠位置為中心縮放；滾輪：左右捲動。換到別行時回到整行大小，播放時會跟著翻頁。

### 吸附到發聲起點

選單「工具 → 拖曳時吸附到發聲起點」打開後（預設關閉），在波形和全曲時間軸上拖曳邊界時，8 像素內有聲音開始的地方就會吸過去；這些位置會在下緣畫成小刻度。拖曳時按住 Alt 暫時不吸。發聲起點是用整首混音算的，鼓聲等樂器也會被抓到，所以只在很近時才吸。

### 沿用既有的 `\k`

開啟已經有 `\k` 的 ASS 時，`\k` 總和至少佔行長一半的行會直接當成打好（◆），匯出時原樣保留；重敲或拖曳之後才會改寫。

### 行時間模式（T 切換，沒有套用奇偶版面時）

- **保留行時間**（預設）：不改 ASS 原本的行開始／結束，只填 `\k`。第一下之前的空白會放進行首的空 `{\k}`，最後剩下的時間給最後的間隔音節或最後一個音節。敲到行開始之前或行結束之後會標成 ⚠；逐行模式下會暫停讓你選「延長行時間」或「重敲」，之後也可以在行清單選那一行按 E 延長。
- **由打軸決定**：第一下＝行開始，最後一個音節結束＝行結束，可以在設定加前後留白。

不管哪種模式，`\k` 都是把每個邊界先四捨五入到 10ms 再相減，所以同一行的 `\k` 總和剛好等於行長。

## ③ 版面與輸出

用新專案建立的檔案會套用版面（一般開啟的 ASS 預設不套用，可以在這頁打勾）。規則依每行實際的演唱時間計算，打完音節會自動重算。「排數」可以選雙行（奇偶兩排交替，預設）或單行。

**單行**：每行都用「單行樣式」，比開唱早「提前出現」的時間出現，但不會早於上一行消失（加上間隔）；擠不下時改成開唱時出現並標紅。

**雙行（奇偶）**：

- 兩行間隔超過 **分段間隔**（預設 2 秒）就分成新的一段。
- 一段只有一行時，用「整段只有一行時的樣式」（預設 Default），開唱時出現。
- 其他情況奇數行、偶數行交替使用兩個樣式（預設 Odd／Even）：第一行比開唱早 **段首提前出現**（預設 1 秒）出現，第二行和第一行同時出現，之後每一行在同一排的上一行消失後 **同排接續間隔**（預設 0.3 秒）出現。
- 每行在唱完後 **唱完後停留**（預設 0 秒）消失。

表格列出每一行的樣式和出現／消失時間。紅字＝依規則算出來時已經開唱了（通常是上一行太短），這時改成開唱時出現；可以雙擊「出現」或「消失」手動改時間（藍字＝手動），「清除選取行的手動時間」可以改回規則。

匯出時：音節打好的行寫入 `\k`、時間和樣式；只打了行軸的行套用時間和樣式，`\k1` 保持原樣；還沒打行軸的行保持原樣。

檔案裡沒有 template／code 行時，匯出會問要不要把內建預設樣板的 template／code 行（和缺少的樣式）加進匯出的檔案，不然 Apply Karaoke Template 不會有效果。

## ④ 預覽

照匯出後的 ASS，在影片大小（`PlayResX`／`PlayResY`）的黑底畫面上畫出每行：樣式的字型、大小、顏色、外框、對齊和邊距，振假名畫在漢字上方（有 `樣式名-furigana` 樣式就用它，沒有就用一半大小），跟著音樂從次要色填成主要色（`\kf` 漸進，`\k` 一次變色）。主要色和次要色一樣時（例如預設樣板），唱過的部分用藍色表示。半透明的行是還沒打音節、只打了行軸的行。

只看得到位置、出現時間和 `\k` 對不對；template 做的特效要在 Aegisub 套樣板後才看得到。

空白播放／暫停，←／→ 倒退／前進 2 秒，↑／↓ 跳到上一行／下一行，點下方時間軸跳到那裡。

### 匯出前檢查

按 Ctrl+E 匯出時會先檢查（也可以從「工具 → 檢查問題…」或 Ctrl+Shift+C 隨時查看）。有錯誤或警告時會列出來，雙擊一項就跳到那一行去修，或按「仍然匯出」：

| 等級 | 項目 |
|---|---|
| 錯誤 | 有音節敲在行的時間外面 |
| 警告 | 音節短於 40ms（多半是誤觸）或長於 3 秒；這行只唱不到 0.5 秒；和下一行重疊；出現時已經開唱；回放時做的標記還沒處理；匯出的樣式沒有 template 行（套樣板不會有效果） |
| 提示 | 還沒打行軸、還沒打音節 |

## 回放檢查與重打

- **回放檢查（W）**：在「② 音節」按 W，照打好的時間播放，大字和歌詞會跟著變色，不用按鍵。看到不對的地方就按打軸鍵（或 Enter）標記剛唱過的那個音節；Backspace 取消上一個標記，↑／↓ 換行，再按一次 W 結束。標記會在字下面畫紅線、清單上顯示 ⚑，也會存進進度檔。
- **跳到下一個標記（N）**：直接從被標記的音節開始重打，前面的音節保留。重打完那一行，它的標記就會清掉。
- **從某個音節開始重打**：在歌詞上按右鍵 →「從這個音節開始重打」，只重打那個音節之後的部分。也可以在這裡標記或取消標記。

## 復原與備份

- **Ctrl+Z／Ctrl+Y**（或 Ctrl+Shift+Z）：復原／重做任何修改，包括打軸、拖曳、切分音節、增刪改行、平移、版面設定、手動時間、清除打軸。「編輯」選單會顯示下一步要復原的是什麼。打軸時的 Backspace 仍然是「復原上一下敲擊」。
- **備份**：開啟專案時和之後每 5 分鐘，進度檔會自動複製一份到 `%LOCALAPPDATA%\karatap\backups`（每個專案保留最近 30 份）。「檔案 → 從備份還原…」可以選一份還原，還原後也可以再按 Ctrl+Z 回來。

## 修改行

建立專案後，在 ① 或 ② 的行清單按右鍵（選單「打軸」裡也有）：

| 動作 | 說明 |
|---|---|
| 修改這行… | 用 `[漢字|かな]` 的寫法改歌詞，會重新一字一音節拆分；換行會在後面多出新的行。這行的音節打軸會清掉，行軸保留 |
| 拆成兩行… | 選要拆開的位置（例如「排気に酔った｜ケーデンス」）。已經打好的音節時間跟著分到兩行；只有行軸時，前半保留行軸、後半要重打 |
| 和下一行合併 | 中間自動加一個空白音節。兩行都打好音節時時間全部保留，行軸合成一段 |
| 在後面插入一行… | 新的一行，還沒有時間 |
| 刪除這行 | 會先確認 |

這些改動只記在進度檔裡，原本的 ASS 不會被改；匯出時才寫進新的 ASS：新增的行是 Effect 為 `karaoke` 的 Comment 行，放在相鄰的行旁邊，刪掉的行不會出現。

## 時間平移（Ctrl+T）

把整首、或清單裡選取的行（可以 Shift／Ctrl 多選）的時間一起往前或往後移：行軸、音節時間和手動設定的出現／消失時間都會移動，奇偶版面自動重算。正數往後、負數往前；要復原按 Ctrl+Z。沒套用奇偶版面的舊 ASS 裡，完全沒打過軸的行沒有工具管理的時間，不會跟著移（要整檔平移請用 Aegisub 的 Shift Times）。

## 慢速播放（S、P）

- S 在 1／0.75／0.5 倍之間切換（速度清單可以在設定改）。
- 預設變調（音高跟著變低），每個速度一秒內就能準備好。
- 按 P 切換成保持音高：第一次產生要幾十秒，之後會快取。保持音高的時間伸縮會讓打擊聲稍微提早，工具會實測並自動補償。
- 不管用哪種速度，算出來的都是原速歌曲的時間。

## 會處理哪些行

和 Aegisub 的 Karaoke Templater 判斷方式相同：

- Effect 欄是 `karaoke` 的行（Dialogue 或 Comment 都算，也就是套過樣板的檔案）；
- Effect 欄空白、含 `\k` 的 Dialogue（還沒套樣板的檔案）。

新專案建立的歌詞行是 Effect 為 `karaoke` 的 Comment 行。template／code／fx 行和其他所有內容都不會動；沒有變動的行，匯出後和原檔逐字元相同（包含編碼、BOM 和換行）。

## 檔案放在哪裡

| 檔案 | 位置 |
|---|---|
| 進度（行軸、音節打軸結果、音節切分調整、行的增刪改、版面設定） | ASS 旁邊的 `檔名.karatap.json`，自動存 |
| 匯出的 ASS | 預設 `檔名.timed.ass`，不能覆蓋原檔 |
| 設定 | `%APPDATA%\karatap\settings.json` |
| 進度檔的自動備份 | `%LOCALAPPDATA%\karatap\backups` |
| 慢速版本的快取 | `%LOCALAPPDATA%\karatap\cache`（可以直接刪） |

## 開發

```bash
.venv/Scripts/python -m pip install pytest
.venv/Scripts/python -m pytest
```

測試不需要音效卡（計時邏輯和播放是分開的）。程式結構：

| 模組 | 內容 |
|---|---|
| `karatap/ass_doc.py` | ASS 讀寫（原樣保留每一行） |
| `karatap/karaoke.py` | 音節、間隔音節、振假名、切分與合併 |
| `karatap/lyrics.py` | 歌詞網頁／文字 → 一字一音節的卡拉OK行 |
| `karatap/readings.py` | 詞的振假名分到每個漢字 |
| `karatap/project.py` | 從樣板 ASS 建立新專案、內建預設樣板、匯出時補 template 行 |
| `karatap/preview.py` | 預覽：樣式、振假名分組、`\k` 填色進度 |
| `karatap/timing.py` | 按鍵事件 → 音節邊界 → `\k` |
| `karatap/layout.py` | 版面規則（雙行奇偶、單行） |
| `karatap/clock.py` | 系統時間 ↔ 歌曲時間 |
| `karatap/audio.py` | ffmpeg 解碼、慢速版本、播放 |
| `karatap/waveform.py` | 波形與頻譜 |
| `karatap/onsets.py` | 發聲起點（吸附用） |
| `karatap/controller.py` | 打軸流程、進度檔、匯出 |
| `karatap/ui/` | PySide6 介面 |

打包 Windows 版（需要先在 venv 裝 PyInstaller）：

```bash
.venv/Scripts/python packaging/build_windows.py v0.2.0
```

會產生 `dist/karatap-v0.2.0-windows-x64.zip`。

漢字讀音表 `karatap/data/kanji_readings.txt` 是用 `packaging/build_kanji_readings.py` 從 KANJIDIC2 產生的。

[llm_syllable_split_prompt.md](llm_syllable_split_prompt.md) 是舊流程用的 LLM 提示詞：把以詞為單位的 `{\k1}` 歌詞拆成一字一音節。新專案精靈已經會自動拆，通常用不到。
