# karatap

音遊式的卡拉OK打軸工具。播放歌曲，用鍵盤跟著敲每個音節，工具算出 Aegisub 的 `\k` 時間，匯出成新的 ASS。

適合這樣的流程：行時間已經用 Arctime 打好、歌詞已經拆成音節，只差每個音節的 `\k`，不想在 Aegisub 裡一個一個拉。

## 安裝

### 用打包好的版本（Windows）
1. 從 [Releases](https://github.com/spt22kousis/asskaramaker/releases) 下載 `karatap-<版本>-windows-x64.zip`，解壓縮。
2. 安裝 [ffmpeg](https://ffmpeg.org/download.html) 並加進 PATH（用來讀影片的音訊、產生慢速版本）。
3. 執行 `karatap.exe`。

想確認環境沒問題，可以執行 `karatap.exe --selftest report.txt`，結果會寫進 `report.txt`，最後一行是 `OK` 就沒問題。

### 從原始碼執行
需要 Python 3.13（其他版本沒測過）和 ffmpeg。

```bash
python -m venv .venv
.venv/Scripts/python -m pip install PySide6 sounddevice numpy
.venv/Scripts/python -m karatap 歌詞.ass
```

## 整體流程

1. **行時間**：用 Arctime 打好每一行的開始／結束，匯出 ASS（或 SRT 再轉成 ASS）。
2. **振假名**：用 Ruby 語法轉換器產生 `{\k1}漢字|<かな{\k1}` 格式的歌詞（以詞為單位）。
3. **拆音節**：把 [llm_syllable_split_prompt.md](llm_syllable_split_prompt.md) 的內容和歌詞一起貼給 LLM，拆成一字一音節，例如
   `{\k1}新作動画|<しんさくどうが{\k1}` → `{\k1}新|<しん{\k1}作|<さく{\k1}動|<どう{\k1}画|<が`
   再把結果貼回 ASS 的 Text 欄。
4. **打軸**：用 karatap 開啟 ASS，跟著歌敲。
5. **匯出**：按 Ctrl+E 另存新的 ASS（預設 `檔名.timed.ass`），原檔不會被改。
6. **套樣板**：在 Aegisub 裡對匯出的檔案 Apply Karaoke Template。

## 開始打軸

1. **開啟 ASS**：`karatap.exe 歌詞.ass`，或在程式裡按 Ctrl+O。
   媒體檔會依序這樣找：ASS 裡 Aegisub 記錄的 Audio File／Video File → 和 ASS 同名的 mp4／mkv／mp3／m4a／flac／wav → 都找不到就讓你選。
2. **延遲校正**（第一次建議做）：按 Ctrl+L，跟著節拍器用打軸鍵或空白鍵敲。前 4 下不計，敲滿 8 下以上就能按「套用」。之後每一下敲擊都會扣掉這個延遲。
3. **播放**：按空白鍵，會從目前這行開始前 1 秒（pre-roll）播放。
4. **敲**：畫面中間的大字是「下一個要敲的音節」，有振假名的會一起顯示；同一個漢字的下一拍（`#|<…`）會標出來。旁邊的小字是接下來的音節。

左邊是行清單：○ 未敲、◐ 敲到一半、● 已敲、⚠ 敲出界。雙擊可以跳到那一行。

## 打軸模式（M 切換）

| 模式 | 怎麼敲 | 音節長度 |
|---|---|---|
| 長按（預設） | 按下＝音節開始，放開＝音節結束 | 按住的時間 |
| 起點 | 只看按下 | 到下一次按下為止 |

- 長按模式可以用好幾個鍵交替敲（像音遊的雙押）：前一鍵還沒放開就按下一鍵，前一個音節就在這一刻結束。
- 按鍵的自動重複會被忽略，長按不會變成連打。
- 長按模式放開後到下一次按下之間的空白：中間有間隔音節就填進去，沒有的話預設併進前一個音節（設定裡可以改成自動插入空的 `{\k}`）。
- 起點模式下，一行最後一個音節的結束預設是放開按鍵，也可以在設定改成按結束鍵（預設 L）。

## 行時間模式（T 切換）

- **保留行時間**（預設）：不改 ASS 原本的行開始／結束，只填 `\k`。第一下之前的空白會放進行首的空 `{\k}`，最後剩下的時間給最後的間隔音節或最後一個音節。
  敲到行開始之前或行結束之後，會標成 ⚠。逐行模式下會暫停讓你選「延長行時間」或「重敲」；之後也可以在行清單選那一行按 E 延長。
- **由打軸決定**：第一下＝行開始，最後一個音節結束＝行結束，可以在設定加前後留白。

不管哪種模式，`\k` 都是把每個邊界先四捨五入到 10ms 再相減，所以同一行的 `\k` 總和剛好等於行長。

## 逐行／連續（C 切換）

- **逐行**（預設）：敲完一行會自動跳到下一行的 pre-roll。一行結束 1.5 秒還沒敲完（而且沒有按著鍵），就自動重播這一行。
- **連續**：整首不停。一行完全沒敲、而且已經過了行尾 0.3 秒，就跳過那一行。

## 間隔音節

文字是空的、或只有空白和標點（`！`、`「`、`"`、`……` 等）的音節是間隔音節：不用敲，時間由工具依上面的規則填。`&`（唱成 "and"）和 `♡` 這類符號照樣要敲。

## 調整音節切分

暫停時，目前那一行的字與字之間會出現標記：

- **紫線**：現有的分界，點一下合併。
- **灰線**：不能合併的分界，例如振假名音節和一般文字之間，因為 `|<` 後面接的文字會被當成讀音。
- **點**：可以切開的地方，點一下切開。漢字是切讀音（點振假名那一列，例如 `新|<しん` → し／ん），假名是切字。

切分的調整存在進度檔，匯出時才寫進新的 ASS。改到已經打好的行會先問你，因為那行的打軸結果會被清掉。選單「打軸 → 還原目前這行的音節切分」可以改回 ASS 原本的拆法。

## 慢速播放（S、P）

- S 在 1／0.75／0.5 倍之間切換（速度清單可以在設定改）。
- 預設變調（音高跟著變低），每個速度一秒內就能準備好。
- 按 P 切換成保持音高：第一次產生要幾十秒，之後會快取。保持音高的時間伸縮會讓打擊聲稍微提早，工具會實測並自動補償。
- 不管用哪種速度，算出來的都是原速歌曲的時間。

| ← → | 倒退／前進 2 秒 |

## 會處理哪些行

和 Aegisub 的 Karaoke Templater 判斷方式相同：

- Effect 欄是 `karaoke` 的行（Dialogue 或 Comment 都算，也就是套過樣板的檔案）；
- Effect 欄空白、含 `\k` 的 Dialogue（還沒套樣板的檔案）。

template／code／fx 行和其他所有內容都不會動。沒打軸的行，匯出後和原檔逐字元相同（包含編碼、BOM 和換行）。

## 檔案放在哪裡

| 檔案 | 位置 |
|---|---|
| 進度（打軸結果、音節切分調整） | ASS 旁邊的 `檔名.karatap.json`，每敲完一行自動存 |
| 匯出的 ASS | 預設 `檔名.timed.ass`，不能覆蓋原檔 |
| 設定 | `%APPDATA%\karatap\settings.json` |
| 慢速版本的快取 | `%LOCALAPPDATA%\karatap\cache`（可以直接刪） |

## 開發

```bash
.venv/Scripts/python -m pip install pytest
.venv/Scripts/python -m pytest
```

測試不需要音效卡（計時邏輯和播放是分開的）。程式結構：

| 模組 | 內容 |
|---|---|
| `karatap/ass_doc.py` | ASS 讀寫（原樣保留每一行） |
| `karatap/karaoke.py` | 音節、間隔音節、振假名、切分與合併 |
| `karatap/timing.py` | 按鍵事件 → 音節邊界 → `\k` |
| `karatap/clock.py` | 系統時間 ↔ 歌曲時間 |
| `karatap/audio.py` | ffmpeg 解碼、慢速版本、播放 |
| `karatap/controller.py` | 打軸流程、進度檔、匯出 |
| `karatap/ui/` | PySide6 介面 |

打包 Windows 版（需要先在 venv 裝 PyInstaller）：

```bash
.venv/Scripts/python packaging/build_windows.py v0.1.0
```

會產生 `dist/karatap-v0.1.0-windows-x64.zip`。
